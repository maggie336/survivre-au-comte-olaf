# Survivre au comte Olaf

Jeu d'aventure complet d'après les *Désastreuses aventures des orphelins Baudelaire*.

## Jouer

Ouvrez `jeu.html` dans votre navigateur. Aucune installation, aucun compte requis.

Choisissez votre personnage (Violette, Klaus, Prunille ou le comte Olaf), jouez seul
ou à deux, échappez à Olaf et visitez les 4 maisons — le château du comte Olaf,
la maison de l'oncle Monty, la maison de la tante Joséphine au bord du lac, puis
la scierie Lucky Smells — jusqu'à être retrouvé.

## Contenu du dépôt

- `SKILL.md` : la fiche du skill pour les assistants IA (comment lancer le jeu).
- `jeu.html` : le jeu complet, interface graphique inchangée.
- `assets/` : les images du jeu.
